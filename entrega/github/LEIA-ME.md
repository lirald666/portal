# Já Deu Certo

Portal de manchetes da Paraíba, do Brasil e do mundo para o domínio jadeucerto.com.

## O que publicar no GitHub

O aplicativo que roda no preview é a versão completa (React + rotas da capa, editorias, matéria, busca, sobre, contato, privacidade, termos, automação e mapa, mais o botão Apoio).

Ao copiar este repositório de trabalho, envie o código do app sem `node_modules`. Páginas obrigatórias para revisão de anúncio:

- `/sobre`
- `/contato`
- `/privacidade` (cookies, Analytics G-1V0JM8J72L, editor ca-pub-5066020163837493)
- `/termos`

## O que não entra no ar

Não publique o chat antigo de bancas, cotações de milhar, bônus de recarga, cassino ou links de aposta. Isso contraria as políticas do AdSense e não faz parte deste portal.
