# Planilha

1. Crie uma planilha Google em branco.
2. Arquivo → Importar → `noticias-modelo.csv` → substituir a planilha atual (ou a primeira aba).
3. Renomeie a aba para `noticias` se a importação tiver mudado o nome.
4. Não apague a primeira linha (cabeçalho).
5. `status`: use `publicado` para sair no JSON e `revisar` para esconder a linha.
6. O script não regrava uma URL que já existe na coluna `url`.
